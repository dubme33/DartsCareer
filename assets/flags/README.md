# Country flags

Local 4:3 SVG flags from [flag-icons](https://github.com/lipis/flag-icons), by Panayiotis Lipiridis. Licensed under MIT; see LICENSE.

Only countries in the game’s `worldRegions` dictionary are included. Refresh with `node --use-system-ca tools/update-walkon-flags.cjs`. Walk-ons use these assets without a network connection.
